본 웹페이지("경제시황분석 브리핑 뷰어")는 개발자 본인이 개인적으로 사용하기 위해 만든 정적 웹사이트이며, 별도의 서버나 백엔드 없이 GitHub Pages에서 정적 파일로만 제공됩니다.

수집하는 정보

이 사이트는 별도의 서버가 없으므로 사용자의 정보를 수집, 저장, 전송하지 않습니다. 로그인 시 Google 계정 인증은 브라우저와 Google 서버 간에 직접 이루어지며, 이 사이트 운영자(또는 그 어떤 제3자 서버)도 로그인 정보나 접근 토큰을 전달받거나 저장하지 않습니다.

Google 사용자 데이터 접근 방식

이 사이트는 Google OAuth 2.0을 통해 로그인한 사용자 본인의 Google Drive 콘텐츠를 읽기 전용(drive.readonly) 권한으로만 조회합니다. 요청하는 범위는 다음과 같습니다.

  • https://www.googleapis.com/auth/drive.readonly — 사용자가 접근 권한을 가진 Google Drive 파일을 읽기 전용으로 조회

브라우저는 로그인한 사용자의 액세스 토큰으로 Google Drive API를 직접 호출하여 파일 목록과 내용을 가져옵니다. 이 과정에서 가져온 데이터는 어떤 서버로도 전송되지 않고, 오직 사용자의 브라우저 화면에 표시하는 용도로만 사용되며 별도로 저장되지 않습니다.

제3자 제공 여부

이 사이트를 통해 얻어진 어떠한 데이터도 제3자와 공유하거나 판매하지 않습니다.
